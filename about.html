About the Project

Problem Statement

In the modern digital era, E-Commerce platforms are prime targets for cyberattacks including DDoS, brute-force logins, payment fraud, and malicious botnet traffic. Traditional monitoring systems often lack real-time visibility and intuitive visualization, making it difficult for Security Operations Center (SOC) analysts to quickly identify and mitigate threats.

This project aims to solve this by providing a visually intuitive, AI-powered Threat Detection Dashboard that simulates enterprise-grade security monitoring, prioritizing critical alerts, and visualizing attack vectors in real-time.

Technologies Used

This is a frontend-only static web application built without any backend dependencies, making it perfect for rapid prototyping and exhibitions.

HTML5
CSS3 (Glassmorphism & Flexbox/Grid)
Vanilla JavaScript (ES6+)
Chart.js (Data Visualization)
FontAwesome (Icons)

Project Objectives & Features

  • Real-time Simulation: Utilize JavaScript timers to simulate live incoming threat data and notification popups.
  • Data Visualization: Implement interactive Line, Bar, Pie, Doughnut, and Area charts to represent complex security data.
  • Enterprise UI/UX: Design a dark-themed, glassmorphism UI reminiscent of professional SOC dashboards.
  • Threat Profiling: Track suspicious users, calculate risk scores, and monitor geographic attack origins.

Designed for College Exhibitions, Hackathons, and Portfolios.
